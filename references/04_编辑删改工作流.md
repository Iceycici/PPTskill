# 04 · 编辑删改工作流（python-pptx 原位编辑铁律）

> 来源：2026-09-17 zcode 会话实战沉淀——在 69 页用户已手动修改过的课件上完成删 15 页、全篇重编号、35 处文案校对，零格式破坏。本文件是该次作业的全部可复用铁律与算法。

## 1. 总铁律

1. **副本先行**：`cp 文件.pptx deck/backup_原因_日期.pptx` 后才允许打开写。
2. **原位编辑**：用户文件一旦经过手动修改，就**永远不要**用重新生成的方式改它（会丢掉全部手改）。一律 python-pptx 打开→改→save。
3. **只改文本，不动格式**：文字修改落在 run 的 `.text` 上；不碰 `rPr`（字体/字号/颜色/加粗）。
4. **长度守卫**：`新文本长度 ≤ 原文长度 + 2`，防溢出。超长时先找更短的表达或拆分方案。
5. **每次保存前确认锁**：文件被 PowerPoint/WPS 占用时 `prs.save()` 抛 PermissionError。先关文件，或 `Get-Process POWERPNT,wpp,wps,et | Stop-Process -Force`。

## 2. 遍历形状的标准姿势（含组合形状与表格）

```python
def iter_tfs(sl):
    def walk(shapes):
        for sh in shapes:
            if sh.shape_type == 6:            # GROUP：递归下钻
                yield from walk(sh.shapes); continue
            if sh.has_text_frame:
                yield sh.text_frame
            if getattr(sh, "has_table", False) and sh.has_table:
                for row in sh.table.rows:
                    for c in row.cells:
                        yield c.text_frame    # 表格单元格也是 text_frame

```

## 3. 文本替换：run 内优先，跨 run 保格式（fix_para 算法）

这是本 skill 最核心的算法。**直接整段重写会毁掉段内混排格式**，正确做法：

```python
A = "{http://schemas.openxmlformats.org/drawingml/2006/main}"

def fix_para(para, old, new):
    full = "".join(r.text for r in para.runs)
    if old not in full:
        return 0
    # 快路径：old 完整落在单个 run 内
    for r in para.runs:
        if old in r.text:
            r.text = r.text.replace(old, new); return 1
    # 慢路径：old 跨 run。为每个 run 建 (run, start, end) span，
    # 命中段的第一个 run = 自身前缀 + new；其余受影响 run 只留匹配段之后的尾部。
    s = full.index(old); e = s + len(old)
    pos, spans = 0, []
    for r in para.runs:
        spans.append((r, pos, pos + len(r.text))); pos += len(r.text)
    affected = [(r, a, b) for r, a, b in spans if b > s and a < e]
    for k, (r, a, b) in enumerate(affected):
        r.text = (full[a:s] + new) if k == 0 else full[max(e, a):b]
    return 1
```

特点：命中边界之外的所有 run 原样保留 → 粗体前导词、彩色词、中英混排的格式边界毫发无损。

**清单驱动**：把全部替换写成 `(页码, 旧串, 新串, 期望次数)` 清单（JSON 格式见 `assets/fixes清单.example.json`），执行器逐条跑并断言次数，`!!期望N实际M` 立即暴露定位错误。**禁止**无清单的全局 sed 式替换。

## 4. 删页：高索引在前 + drop_rel

```python
from pptx.oxml.ns import qn

def delete_slides(prs, pages_1based):
    for idx in sorted(pages_1based, reverse=True):   # 从高往低删，避免索引位移
        sld = list(prs.slides._sldIdLst)[idx - 1]
        prs.part.drop_rel(sld.get(qn("r:id")))       # 先解除关系，防孤儿 part
        prs.slides._sldIdLst.remove(sld)
```

**必须 drop_rel**：只 remove 节点会留下悬空关系，部分查看器打不开。

## 5. 序号重编：单遍正则，严禁级联

删页后重编号（场景 5→3、6→4……）如果分多遍跑，`5→3` 的结果会被后续 `3→1` 再吃掉。正确做法是**一个映射表 + 单遍 `re.sub`**：

```python
import re
SCENE_MAP = {5: 3, 6: 4, 7: 5, 8: 6, 9: 7, 12: 8}

def renum(text, mapping):
    return re.sub(r"场景\s*(\d+)",
                  lambda m: "场景 " + str(mapping.get(int(m.group(1)), int(m.group(1)))),
                  text)
```

映射外的数字原样保留。应用范围：保留页的 kicker、标题、正文、表格、**演讲备注**（备注里的"见场景 N""练习 N 对应本场景"最容易漏）。

配套两件套：
- **TARGETS 精确子串清单**：处理无编号交叉引用与计数（"12 类高频场景"→"8 类"、"（13 题）"→"（9 题）"），逐条列在 JSON 里；
- **页码重排**：手工页码框不会随删页自动更新，按**位置**找（右下：`top/914400 > 7.0 且 left/914400 > 12.0 且文本 isdigit`），改写为实际 slide 序号。EMU 换算：1 英寸 = 914400 EMU。

## 6. 结构操作

| 操作 | 正确姿势 | 陷阱 |
|---|---|---|
| 删表格行 | `el.getparent().remove(el)` | `tbl._tbl.tr_lst` 是**快照列表**，对它 remove 不脱离 XML 树 |
| 表格重写行高 | `tr.set("h", str(int(英寸*914400)))` | — |
| 段落拆条（1 条拆 2 条） | `copy.deepcopy(p0._p)` → 改克隆体文本 → `p0._p.addnext(newp)` | 从零 new 段落要手工补 pPr/rPr，深拷贝则格式全保留 |
| 删除形状 | `sh._element.getparent().remove(sh._element)`（按填充色+坐标匹配定位） | 只按文本匹配会漏掉空文本框残影 |
| 改中文字体 | 同时设 `a:latin` 与 `a:ea` 的 typeface | 只设 latin 中文会回落默认字体 |
| 单元格写入 | 文本收拢到首 run（`runs[0].text = t`，其余 run 从 XML 删） | 保留首 run 格式，牺牲段内混排（表格内可接受） |

## 7. 校对附带的三项一致性清理

1. **页脚统一**：按位置找（`top>7.0 且 left<2.0` 含课程名的框），**先长后短**两轮替换（先"课程名 · 副标题"→课程名，再"课程名 ·"→课程名），防止先短替换留下悬挂间隔号。
2. **页码修正**：同第 5 节位置法。注意用户手动调换页序后页码不会跟着变，全篇"页码=页序"必须复验。
3. **备注空格规范化**：批量补中英文/数字间空格：

```python
def space_notes(text):
    text = re.sub(r"([\u4e00-\u9fff])([A-Za-z0-9])", r"\1 \2", text)
    text = re.sub(r"([A-Za-z0-9])([\u4e00-\u9fff])", r"\1 \2", text)
    return text
```

**回归防护**：规范化后必须检查路径与 URL 未被破坏（查 `"C :"`、`"http s"`），双空格残留。

## 8. 环境陷阱（Windows 实战）

1. **ps1 中文路径乱码**：无 BOM 的 UTF-8 .ps1 被 PowerShell 5.1 按本地编码读，中文路径变乱码导致"找不到文件"。对策：脚本内**不写中文路径**，用通配符解析：
   ```powershell
   $src = (Get-ChildItem "C:\work" -Filter "AI*.pptx" |
           Where-Object { -not $_.Name.StartsWith("~`$") } | Select-Object -First 1).FullName
   ```
   （顺带排除 Office 锁文件 `~$`。）
2. **锁文件**：`~$xxx.pptx` 存在 = 文件正被 Office 打开。先让用户关闭，或强杀进程。
3. **COM 打开参数**：`Presentations.Open($src, $true, $false, $false)` = ReadOnly、无窗口、不自动宏。用完 `Close()` + `Quit()` + `ReleaseComObject`，否则 POWERPNT 进程残留，下次 COM 调用 RPC 崩溃。
4. **两套 Office 并存**：WPS（`Kwpp` COM）与 PowerPoint 都能渲染；强杀时四个进程名一起处理：`POWERPNT,wpp,wps,et`。
