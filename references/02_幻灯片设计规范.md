# 02 · 幻灯片设计规范（设计令牌全表 + 版式规则）

> 来源：设计原则框架参考官方技能 document-skills:pptx 0.1.4（Z.AI，License: Proprietary）Part 1 "Slide Design Best Practices"，令牌全表与组件规格为 2026-09-17 zcode 会话在 69 页中文教学课件中实战定稿的"深蓝学术风"体系。

## 1. 开工前三决策

1. **内容驱动配色**：先看内容气质定色调（学术→深蓝；少儿→暖橙；数据→青灰），不要反着来。
2. **主次不等权**：每页只允许一个视觉焦点（大数字/大图/大标题三选一），其余元素做层级衬托。
3. **明暗对比 + 母题**：确定"暗底页（篇章页/金句条）↔ 亮底页（内容页）"的节奏，并让某个母题（如篇章色、胶囊标签、▸ 列表符）贯穿全篇。

## 2. 深蓝学术风设计令牌全表（实战定稿值）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `navy` | `0E2A47` | 深蓝底（篇章页、金句条、模板卡、结课页） |
| `navy2` | 略浅深蓝 | 深底页上的卡片分层 |
| `ink` | `1C3D5A` | 亮底页大标题 |

## 3. 页面骨架规格

### 3.1 内容页（`content` 组件）

- kicker（页顶导航小字）：12.5pt、篇章色、加粗，格式 `第N篇 · 章节名 · 子题`；
- 主标题：28pt `ink` 加粗；正文区从 y=1.5" 起；
- 底部金句条（可选）：`quote` 组件，navy 底、`onDark` 白字、左起 ❝ 符号。

### 3.2 篇章页（`divider` 组件）

- 全页 navy 底；右侧 210pt 半透明篇章大数字水印（有意设计的低对比装饰，视觉预检时会误报重叠，属已知豁免）；
- 左上篇章色小字 `PART 0N`；白色大标题；副标题一行；下方条目列表（本篇要点）。

### 3.3 卡片体系

| 组件 | 规格 |
|---|---|
| `card` | roundRect，圆角默认，可选外阴影；间距 ≥0.3" |
| `chip` | 胶囊 `rectRadius=h/2.2`，选中用篇章主色实底白字，未选用 `muted` |
| `promptCard` | navy 底模板卡：金色 label 12.5pt 加粗 + 模板正文多行；模板文字逐字保留 |
| `versus` | 左右双卡：左 `badT` 底红题（反例），右 `goodT` 底绿题（正例） |
| `numRows` | 大数字（篇章色）+ 加粗小标题 + 说明 + 底部细分隔线，行高 0.95–1.1" |
| `flow` | 横向等宽步骤卡 + 卡间"→"；支持 `start` 参数（编号不必从 1 起） |
| `table` | 表头深色白字 + 斑马纹（奇偶行 `F7FAFC`）；单元格可传 `{text, options:{color,bold}}` |
| `bullets` | `▸` 主级 / `–` 次级（`bu`/`bud` 工厂），项数 ≤5，超了拆两栏 |

## 4. 排版细则（中文课件场景）

1. **字号阶梯**：主标题 28 → 小节题 13.5–15 → 正文 12–12.5 → 图注/辅助 10–10.5；正文下限 11.5。
2. **密度控制**：单卡要点 ≤5 条；一页卡片 ≤4 块；表格 ≤8 行，超出拆页或拆栏。
3. **留白**：卡片间距 ≥0.3"；文字与卡边距 0.2–0.25"；页面底部保留 0.4" 以上呼吸区（金句条除外）。
4. **图文关系**：图占 40–60% 时文字只留短句；截图必须配图注；先文后图定骨架，图按 `h=w/ar` 放置防拉伸。
5. **图表优先**：能用流程/对比/表格表达的不用大段文字（官方 "Diagrams strongly preferred"）；数字要"让数据说话"但**只准用资料里真实存在的数字**。
6. **避坑清单**（"AI 味"来源）：每页满铺文字块；五个以上并列纯色小方块；无意义渐变；图标+标题+三要点的机械重复；字体混用；章法不统一。母题（同色 kicker、同位页脚、同款列表符）是对抗"AI 味"的主要手段。

## 5. 一致性强制项（质检会查）

- kicker 格式全篇统一（篇章名+章节名用同一分隔符体系）；
- 页脚全篇唯一形态（发现"课程名 ·""课程名 · 副标题"并存即违规，统一时**先长后短**替换）；
- 页码=物理页序（封面/结课页按设计可无页码，其余必查）；
- 连接号/区间号全篇统一一种（如半角 `3-5`）；
- 同名词表大小写统一（如 Cinematic/Photorealistic 首字母同规则）。
